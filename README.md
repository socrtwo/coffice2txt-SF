## What it does

Coffice2txt uses low-level binary parsing to salvage whatever text remains in a damaged Office document. It bypasses the format checks that prevent Word/Excel/PowerPoint and LibreOffice from opening corrupt files. If there is text in there, this tool will usually find it.

- Extracts text from corrupt DOC, XLS, PPT, DOCX, XLSX, PPTX
- Pure Perl — works wherever Perl runs
- Optional Tk GUI for interactive recovery (`coffice2txt.pl`)
- Command-line workflow for batch processing
- Bundled helper modules (`Spreadsheet::XLSX::TempFolderCreator`, `Spreadsheet::XLSX::Utility2007PDP`, `Spreadsheet::XLSX::ZipMod2`)

**Language:** Perl 5.10+ &middot; **License:** MIT

## Quick start

### Windows

1. Install [Strawberry Perl](https://strawberryperl.com/) (5.32 or newer).
2. Download `coffice2txt-windows-vX.Y.Z.zip` and extract.
3. Double-click `run.bat`, or from a Command Prompt:
   ```cmd
   run.bat path\to\corrupt.docx
   ```

### macOS

1. Install Perl + Tk (Homebrew is easiest):
   ```bash
   brew install perl perl-tk
   ```
2. Download `coffice2txt-macos-vX.Y.Z.tar.gz` and extract.
3. Run:
   ```bash
   ./run.command path/to/corrupt.xls
   ```

### Linux

1. Install Perl, Tk, and required CPAN modules:
   ```bash
   # Debian / Ubuntu
   sudo apt install perl perl-tk libspreadsheet-parseexcel-perl \
                    libspreadsheet-xlsx-perl libtk-tablematrix-perl
   ```
   ```bash
   # Fedora / RHEL
   sudo dnf install perl perl-Tk perl-Spreadsheet-ParseExcel perl-Spreadsheet-XLSX
   ```
2. Download `coffice2txt-linux-vX.Y.Z.tar.gz` and extract.
3. Run:
   ```bash
   chmod +x run.sh
   ./run.sh path/to/corrupt.ppt
   ```

### ChromeOS

ChromeOS runs the Linux bundle inside the built-in Linux (Crostini) container. Enable Linux from Settings &rarr; Advanced &rarr; Developers &rarr; Linux development environment, then follow the [Linux](#linux) instructions above.

### Android (Termux)

1. Install [Termux](https://f-droid.org/packages/com.termux/) from F-Droid (the Play Store version is no longer maintained).
2. In Termux:
   ```bash
   pkg update && pkg install perl wget
   wget https://github.com/socrtwo/coffice2txt-SF/releases/latest/download/coffice2txt-android-vX.Y.Z.tar.gz
   tar -xzf coffice2txt-android-*.tar.gz
   cd coffice2txt-*
   ./setup-termux.sh
   perl coffice2txt.pl path/to/file.docx
   ```
The Tk GUI is unavailable on Android; use the CLI extraction routines.

### iOS / iPadOS

1. Install [a-Shell](https://apps.apple.com/app/a-shell/id1473805438) (preferred) or [iSH](https://apps.apple.com/app/ish-shell/id1436902243) from the App Store.
2. In the shell:
   ```bash
   curl -LO https://github.com/socrtwo/coffice2txt-SF/releases/latest/download/coffice2txt-ios-vX.Y.Z.tar.gz
   tar -xzf coffice2txt-ios-*.tar.gz
   cd coffice2txt-*
   ./setup-ish.sh
   perl coffice2txt.pl path/to/file.xlsx
   ```
The Tk GUI is unavailable on iOS; use the CLI extraction routines.

### Web

The web bundle contains the static landing page used by `https://socrtwo.github.io/coffice2txt-SF/`. Drop the contents on any static host (GitHub Pages, Netlify, S3, etc.) to mirror the live site.

## CLI usage

```bash
perl coffice2txt.pl <file>          # extract text from a single file
perl xlscatPDP <file.xls>           # render an XLS to terminal
perl ss2tk <file.xls>               # browse spreadsheet in a Tk window
```

Run with no arguments to launch the Tk GUI (where Tk is available).

## Building from source

```bash
git clone https://github.com/socrtwo/coffice2txt-SF.git
cd coffice2txt-SF

# install required CPAN modules (cpanminus recommended)
cpanm --installdeps .

# syntax check
perl -c coffice2txt.pl
```

The bundled subdirectories (`Spreadsheet-XLSX-*`) are local copies of the helper Perl modules. You can install them locally with:

```bash
for d in Spreadsheet-XLSX-*; do
  (cd "$d" && perl Makefile.PL && make && make test && make install)
done
```
